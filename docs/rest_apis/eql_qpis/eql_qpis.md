事件查询语言（EQL）是一种用于基于事件的时间序列数据（如日志、指标和追踪）的查询语言。有关 EQL 的概述和相关教程，请参阅 [EQL](https://www.elastic.co/guide/en/elasticsearch/reference/8.18/eql.html)。

- [EQL 搜索](./eql_search)——执行 EQL 搜索查询
- [获取异步 EQL 搜索](./get_async_eql_search)——检索异步 EQL 搜索的结果
- [获取异步 EQL 搜索状态](./get_async_eql_status)——检查异步 EQL 搜索的状态
- [删除异步 EQL 搜索](./delete_async_eql_search)——删除之前启动的异步 EQL 搜索
