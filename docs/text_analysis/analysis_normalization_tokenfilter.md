# 归一化词元过滤器

有若干词元过滤器可尝试对某些语言中的特殊字符进行归一化处理。

## 可用类型

| 语言 | 词元过滤器 |
|---|---|
| 阿拉伯语（Arabic） | `arabic_normalization` |
| 德语（German） | `german_normalization` |
| 印地语（Hindi） | `hindi_normalization` |
| 印度语言（Indic） | `indic_normalization` |
| 库尔德语（索拉尼语，Sorani） | `sorani_normalization` |
| 波斯语（Persian） | `persian_normalization` |
| 斯堪的纳维亚语言（Scandinavian） | `scandinavian_normalization`、`scandinavian_folding` |
| 塞尔维亚语（Serbian） | `serbian_normalization` |
