本指南涵盖开始使用 Elasticsearch 时需要理解的核心概念。如果你更希望立即开始使用 Elasticsearch，可以[设置本地开发环境](../intro/deploy)并跳转到[动手代码示例](../quickstart/quickstart)。

- [什么是 Elasticsearch？](./what_is_es)：了解 Elasticsearch 及其主要用例。
- [运行 Elasticsearch](./deploy)：了解在不同环境中部署 Elasticsearch 的选项，包括快速的本地开发设置。
- [索引和文档](./documents_indices)：理解 Elasticsearch 最重要的基本概念以及它如何存储数据。
- [向 Elasticsearch 添加数据](./ingest_data)：了解将数据摄取到 Elasticsearch 的选项。
- [搜索和分析数据](./search_analyze)：了解在 Elasticsearch 中搜索和分析数据的选项。
- [为生产环境做好准备](./scalability)：了解将 Elasticsearch 部署迁移到生产环境所需的基本概念。
