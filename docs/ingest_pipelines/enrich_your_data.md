# 丰富你的数据

你可以使用富化处理器（enrich processor）在摄取期间将现有索引中的数据添加到传入文档中。

例如，你可以使用富化处理器：

- 基于已知的 IP 地址识别 Web 服务或供应商
- 基于产品 ID 为零售订单添加产品信息
- 基于电子邮件地址补充联系信息
- 基于用户坐标添加邮政编码

## 富化处理器的工作方式

大多数处理器是自包含的，只更改传入文档中的现有数据。

富化处理器会向传入文档添加新数据，因此需要一些特殊的组件：

**富化策略**

一组用于将正确的富化数据添加到正确的传入文档的配置选项。

富化策略包含：

- 一个或多个源索引的列表，这些索引以文档形式存储富化数据
- 策略类型，决定处理器如何将富化数据与传入文档匹配
- 源索引中用于匹配传入文档的一个 `match` 字段
- 富化字段，包含你希望从源索引添加到传入文档的富化数据

在富化策略可以与富化处理器配合使用之前，必须先执行该策略。执行时，富化策略使用策略的源索引中的富化数据创建一个精简的系统索引，称为富化索引。处理器使用此索引来匹配和丰富传入文档。

**源索引**

存储你希望添加到传入文档的富化数据的索引。你可以像管理常规 Elasticsearch 索引一样创建和管理这些索引。你可以在一个富化策略中使用多个源索引，也可以在多个富化策略中使用同一个源索引。

**富化索引**

绑定到特定富化策略的特殊系统索引。

将传入文档与源索引中的文档直接匹配可能缓慢且消耗资源。为了提高速度，富化处理器使用富化索引。

富化索引包含来自源索引的富化数据，但具有一些有助于精简的特殊属性：

- 它们是系统索引，由 Elasticsearch 内部管理，仅用于富化处理器和 ES|QL 的 `ENRICH` 命令。
- 它们始终以 `.enrich-*` 开头。
- 它们是只读的，也就是说你不能直接更改它们。
- 它们经过 force merge 以便快速检索。
