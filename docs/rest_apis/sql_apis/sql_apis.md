# SQL API

Elasticsearch 的 SQL API 允许你在 Elasticsearch 索引和数据流上运行 SQL 查询。有关 Elasticsearch SQL 特性及相关教程的概述，参见[SQL](/explore_analyze/sql/overview)。

:::::::info 新版 API 参考

有关最新的 API 详情，请参阅[SQL API](https://www.elastic.co/docs/api/doc/elasticsearch/group/endpoint-sql)。

:::::::

- [SQL 搜索 API](./sql_search) — 运行 SQL 查询
- [清除 SQL 游标 API](./sql_clear_cursor) — 停止/清除游标资源以进行分页
- [获取异步 SQL 搜索 API](./get_async_sql_search) — 检索异步 SQL 搜索的结果
- [获取异步 SQL 搜索状态 API](./get_async_sql_search_status) — 检查异步 SQL 搜索的状态
- [删除异步 SQL 搜索 API](./delete_async_sql_search) — 删除异步 SQL 搜索
- [SQL 转换 API](./sql_translate) — 将 SQL 转换为 Elasticsearch DSL 查询

> [原文链接](https://www.elastic.co/guide/en/elasticsearch/reference/8.18/sql-apis.html)
