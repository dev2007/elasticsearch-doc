# Phonetic 词元过滤器

`phonetic` 词元过滤器由 [`analysis-phonetic` 插件](https://www.elastic.co/guide/en/elasticsearch/plugins/8.18/analysis-phonetic.html)提供。

:::::important 重要
要使用 phonetic 词元过滤器，必须先安装 `analysis-phonetic` 插件。有关安装说明和该插件提供的编码器（encoder）配置，请参阅插件文档。
:::::

> [原文链接](https://www.elastic.co/guide/en/elasticsearch/reference/8.18/analysis-phonetic-tokenfilter.html)
