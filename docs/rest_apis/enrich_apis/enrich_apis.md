# 富化 API

::::info 新版 API 参考

有关最新的 API 详情，请参阅[富化 API](https://www.elastic.co/docs/api/doc/elasticsearch/v8/group/endpoint-enrich)。

::::

以下富化 API 可用于管理富化策略：

- [创建富化策略](./put_enrich_policy)——创建或替换富化策略
- [删除富化策略](./delete_enrich_policy)——删除富化策略
- [获取富化策略](./get_enrich_policy)——返回有关富化策略的信息
- [执行富化策略](./execute_enrich_policy)——执行富化策略
- [富化统计信息](./enrich_stats)——获取富化相关统计信息

> [原文链接](https://www.elastic.co/guide/en/elasticsearch/reference/8.18/enrich-apis.html)
