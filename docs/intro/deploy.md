# 运行 Elasticsearch

要使用 Elasticsearch，你需要一个正在运行的 Elasticsearch 服务实例。你可以通过多种方式部署 Elasticsearch。

### 快速开始选项

- **本地开发**：使用最小的本地 Docker 设置快速开始开发和测试。

### 托管选项

- **Elastic Cloud Hosted**：Elasticsearch 可作为托管 Elastic Stack 产品的一部分，部署在你选择的云提供商上。注册 14 天免费试用。
- **Elastic Cloud Serverless**：创建无服务器项目，获得自动伸缩且完全托管的 Elasticsearch 部署。注册 14 天免费试用。

### 高级选项

- **自管理**：在你自己的场所安装、配置和运行 Elasticsearch。
- **Elastic Cloud Enterprise**：在公有云或私有云、虚拟机或你自己的场所上部署 Elastic Cloud。
- **Elastic Cloud on Kubernetes**：在 Kubernetes 上部署 Elastic Cloud。
